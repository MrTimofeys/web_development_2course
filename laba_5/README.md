# Лабораторная работа 5

Flask-приложение для управления учетными записями пользователей,
проверки прав по ролям и формирования отчетов по журналу посещений.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/flask --app app run
```

При первом запуске автоматически создается SQLite-база `instance/laba_5.sqlite`,
таблицы `roles`, `users`, `visit_logs`, две роли и два тестовых пользователя.

Данные для входа администратора:

- логин: `admin`
- пароль: `Admin123`

Данные для входа обычного пользователя:

- логин: `student`
- пароль: `Student123`
